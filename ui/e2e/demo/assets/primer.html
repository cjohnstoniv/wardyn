The floor we all stand on

Your machines already run strangers’ code, every day.

npm install Every dependency install executes code you never read — running alongside your documents, credentials, and data.
Build & install scripts Postinstall hooks and Makefiles run with everything your shell can reach.
CI jobs All of the above, unattended, with the deploy keys nearby.
Supply-chain attacks have been exploiting this for years. event-stream · ua-parser-js · Codecov
It didn’t start with AI. AI just gives it a new set of hands.
Now add hands

An AI coding agent is that same exposure — with hands.

$runs commands
~edits files
+installs packages
↗calls APIs
It often does those things as you — every file you can read, every credential your environment can reach, it may reach too.
prompt injection — a dependency, a web page, or a file the agent reads can carry someone else’s instructions.

The usual answers

Trust it all, or block it all.

Trust it Give the agent access to everything — and hope it behaves.
Block it Lock everything down so tightly the agent can’t do anything useful.

Govern without guessing

Nobody can predict a tool’s needs. So don’t guess — observe.

1 · RUN
Run the job once, watched
One watched run, in a controlled environment, everything logged.
2 · SEE
See what it actually reached
Which hosts, which services, which destinations — evidence, not a guess.
3 · DECIDE
Turn that evidence into policy
Allow, deny, or ask for approval — and keep the decision on the record.
one safe, watched run → a policy you can keep — ep 9
