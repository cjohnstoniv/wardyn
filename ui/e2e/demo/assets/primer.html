The floor we all stand on

Your machines already run strangers’ code, every day.

npm install Every dependency pull executes code you never read — beside your credentials.
Build & install scripts Postinstall hooks and Makefiles run with everything your shell can reach.
CI jobs All of the above, unattended, with the deploy keys nearby.
Supply-chain attacks live exactly here — one compromised package, quietly reading and shipping out.

The usual answers

Trust it all, or block it all.

Trust it Every script and agent works beside your keys. The traffic goes unwatched. You find out afterward.
Block it The security team wins the argument. The productivity never arrives. Everyone loses quietly.
