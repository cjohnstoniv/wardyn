Ephemeral scratch

The writable layer a run gets when it mounts no drive. It is wiped when the sandbox exits.

16384
Size limited by eviction — over it, the run is stopped, not the write
A run asking for more is clamped to this, not refused.

Drive ceiling

Off means this deployment offers no drives: nothing is mounted and every drive write is refused. Existing drives and allocations are kept.
32768
An allocation or override above this is refused at write and clamped at resolve. 0 means no ceiling.
A ceiling bounds what an admin may allocate. It does not bound what the volume will hold.
