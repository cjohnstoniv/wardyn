# Permissive, distribution-safe SPDX identifiers — the SINGLE allowlist, read by BOTH the Go
# gate (`make licenses`) and the UI gate (`make npm-license`). Two lists that must agree will
# drift; one cannot.
#
# Enumerate ids. Do NOT add wildcards: a bare `BSD` token is an unversioned, legally ambiguous
# declaration, and `BSD-*` admits BSD-4-Clause (advertising clause) and BSD-Protection
# (copyleft-ish). An allowlist with a wildcard in it is a denylist wearing a costume.
#
# Every id below is present in the current dependency set:
#   Go shipped modules   : Apache-2.0, BSD-3-Clause, MIT, ISC, BSD-2-Clause
#   UI production deps   : MIT, Apache-2.0, OFL-1.1, ISC, 0BSD
#
# Every id here is BACKED by a canonical text in licenses/canonical/ and IN USE by
# a current dependency. Adding an id means adding its text in the same commit —
# otherwise the notices generator emits nothing for it and the gap is silent.
#
# Extend deliberately, with review. CODEOWNERS routes any change here to the maintainer.
0BSD
Apache-2.0
BSD-2-Clause
BSD-3-Clause
ISC
MIT
OFL-1.1
